# mdb2mdb — MDB 字段属性规范化工具

按《B.2 属性项定义与内容要求》批量规范 Access / ArcGIS 个人地理数据库（.mdb）的字段属性：

1. 输入一个 mdb 文件；
2. 遍历所有表结构，字段名与标准属性项名相同（不区分大小写）的，把字段改为标准规定的数据类型、长度和小数位数，
   并按标准设置“是否允许为空”；
3. 删除 `Shape_Length`、`Shape_Area` 字段；
4. 输出处理后的新 mdb 文件（**输入文件不会被修改**）。

## 使用

运行环境：Windows 7 及以上（.NET Framework 4.x 和 Jet 4.0 为系统自带，装有 ArcGIS 10.x 的电脑均可直接运行）。

- **图形界面**：双击 `mdb2mdb.exe`，选择或拖入 mdb 文件，点击“开始处理”。
  默认输出为同目录下的 `原文件名_更新.mdb`，处理日志为 `原文件名_更新_处理日志.txt`。
- **拖放**：把 mdb 文件直接拖到 `mdb2mdb.exe` 图标上，会自动开始处理。
- **命令行**：`mdb2mdb.exe --cli 输入.mdb [输出.mdb]`
  返回码：0 = 成功，1 = 部分字段处理出错（见日志），2 = 处理失败。

处理前请先在 ArcMap / Access 中关闭该 mdb。

## 处理规则

| 标准类型 | mdb 中的字段类型 | 说明 |
|---|---|---|
| TEXT | 文本，字段大小 = 标准长度 | 原数据超长时截断，并在日志中给出警告 |
| LONG | 长整型 | 有效性规则限制位数（如 GB 长度 6：-999999～999999）；小数会四舍五入，无法转换的值置为空，均有警告 |
| FLOAT | 单精度型 | 有效性规则限制位数（如 ANGLE 长度 4、小数 1 位：最多 3 位整数）；“小数位数”设为标准值 |
| DOUBLE | 双精度型 | 同 FLOAT；未规定小数位数的（SAREA）按整数位数限制 |
| DATE | 日期/时间 | 字段属性“格式”设为 `yyyy/mm/dd hh:nn:ss` |

- 只处理用户表；Access 系统表（MSys*）、ArcGIS 系统表（GDB_*）和空间索引表（*_Shape_Index）不处理。
- 类型已符合标准的字段不改动数据，只补设小数位数/格式。
- 是否允许为空：按标准设置 Access 字段的“必需”属性（GB、CLASS 为不允许为空，其余为允许为空）。
  若某字段按标准不允许为空、但已有记录为空值，则该字段保持允许为空并在日志中警告（需先补全数据再处理）。
  这里的“空”指空值(Null)，空字符串不在检查范围内。
- 修改类型前先只读检查全部数据：完全无损时由 Jet 直接修改字段类型；
  有值会被截断/取整/置空时，由程序逐条转换并在日志中列出受影响的记录数。字段位置保持不变。
- 字段上的索引会在修改后重建；允许空字符串、默认值、说明等属性会保留。
- 对 ArcGIS 个人地理数据库，同步更新 `GDB_Items` 中要素类定义：修改字段的 `FieldType` 和 `IsNullable`，
  移除被删除字段的定义并清空 `AreaFieldName` / `LengthFieldName`。
- 处理完成后压缩数据库（可在界面中取消）。

### 关于数值型字段的“长度”

mdb 的长整型/单精度型/双精度型字段本身没有“长度（精度）”属性，因此程序为这些字段设置 Access 的
**有效性规则**（如 `Is Null Or Between -999999 And 999999`）和有效性文本（如“GB（分类代码）超出标准长度：最多 6 位数字。”）。
该规则由 Jet 引擎强制执行：在 Access 中录入、在 ArcMap 中编辑时，超出位数的值都会被拒绝。

- 长度按“总位数”理解：长度 4、小数 1 位 → 最多 3 位整数（-999.9～999.9）。
- 已有数据超出位数的字段不设置规则，并在日志中警告（需先修正数据再处理）。
- “小数位数”写入 Access 字段属性，影响显示；数值本身多出的小数位不会被截断或拒绝。
- 文本字段的长度由字段大小直接限制，无需规则。

## 编译

```
dotnet build src/Mdb2Mdb/Mdb2Mdb.csproj -c Release          # 输出 src/Mdb2Mdb/bin/Release/net40/mdb2mdb.exe
dotnet test  tests/Mdb2Mdb.Tests/Mdb2Mdb.Tests.csproj         # 单元测试（任意平台）
```

`tests/Mdb2Mdb.E2E` 是端到端测试，需要在 Windows 上运行（依赖 Jet/DAO），GitHub Actions 中会自动执行并上传编译好的 exe。

标准属性项表定义在 `src/Mdb2Mdb/FieldSpecs.cs`，标准变化时修改此文件即可。
